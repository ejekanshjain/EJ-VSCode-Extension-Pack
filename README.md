# EJ's VS Code Extension Pack

A curated VS Code extension pack for Ekansh Jain's TypeScript, web, Go, Terraform, and Bun development workflow.

## Included tooling

- Better Comments, Error Lens, Pretty TypeScript Errors, and Color Highlight
- ESLint, Prettier, and Tailwind CSS IntelliSense
- GitLens and GitHub Copilot Chat
- Bun, Go, and Terraform language tooling
- REST Client and Thunder Client
- Material Icon Theme and SynthWave '84

The exact extension identifiers are maintained in package.json.

## Build a VSIX

    npm install
    npm run package

This produces a local VSIX package through @vscode/vsce.

## Related repository

Editor preferences and the exportable extension list live in [vscode-settings](https://github.com/ejekanshjain/vscode-settings).
